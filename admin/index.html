Paste your GitHub access token to manage listings and photos.

How do I get a token? (one-time setup)
  1. Go to github.com → click your profile photo → Settings.
  2. Scroll to Developer settings (bottom of left sidebar).
  3. Click Personal access tokens → Fine-grained tokens → Generate new token.
  4. Name it "HAYCHIC Admin". Under Repository access, choose "Only select repositories" and pick haychic-boutique.
  5. Under Permissions → Repository permissions, set Contents to "Read and write".
  6. Click Generate token and copy it — paste it above. It's saved only in this browser.
